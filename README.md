# AirBNC

Project - Building an API for a property rental service, inspired by platforms like AirBnb. This backend service powers a property-rental platform where users can look through listings and choose accommodation that suits their next journey.

# Stack & Tools

Languages & Frameworks: JavaScript, Express
Database: PostgreSQL
Testing: Supertest
Hosting: Supabase (database), Render (server)

# Live API

https://pt-be-airbnc-51jq.onrender.com

# Setting up the local test database with a script

- run `npm install` to install the necessary dependencies

PostgresSQL is used to manage the test database

To create the database 'airbnc_test', run:

psql -f db/airbnc_test.sql
